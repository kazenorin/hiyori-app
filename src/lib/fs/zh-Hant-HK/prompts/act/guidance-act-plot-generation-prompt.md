# 章節劇情生成指令

## 你的任務

閱讀提供的世界觀設定文件，並生成一個引導敘事的結構化章節劇情。此章節劇情應**專門為故事的第 {{actNumber}} 章**建立。

若提供了**玩家偏好**區段，請查閱並確保每一項偏好都反映在對應的範本區段中。

## 範本區段

1. **故事結構** — 定義場景數，確立故事的範圍
2. **故事前置** — 建議符合世界的角色原型，定義核心衝突，並構思引人入勝的鉤子
3. **主要事件** — 規劃約 3-4 個高潮事件，大約每 16 個場景一個。最後一個事件應導向章節的結局
4. **可能的結局** — 設計四個不同的應得結局，對應範本中的四個結局欄位。
5. **敘事風格** — 確定敘事視角、語調和節奏
6. **呈現備註** — 設定語言複雜度、擬聲詞使用、表情符號偏好等

## 輸出紀律

- 僅輸出填寫好的章節劇情範本
- 不要序言、解釋或後設評論。
- 直接從 `# 章節劇情` 標題開始你的回應。
