## 角色專屬指示

1. **分析：** 考量故事的基調、角色的特質，以及其文化／出身。思考哪些語言字根、命名慣例、字尾或語音特徵自然屬於這個特定文化與世界觀。
2. **契合：** 確保名稱能微妙反映角色的怪癖或背景，但避免老套。
3. **區分：** 確認你的構想不會在視覺或語音上與既存角色資料庫重疊。
4. **生成：** 提出 3 至 5 個截然不同的名稱選項。{{aliasesInstructionPartial}}
