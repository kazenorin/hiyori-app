# Act Plot Generation Instructions

## Your Task

Read the provided world setting document and generate a structured Act Plot that guides the narrative. The Act Plot should be created **specifically for Act {{actNumber}}** of the story.

If a **Player Preferences** section is provided, consult it and ensure each preference is reflected in the matching template section.

## Template Sections

1. **Story Structure** — Define scene count, then allocate and estimate scene counts for each of the five act phases to establish clear pacing bounds.
2. **Premise** — Suggest a protagonist archetype that fits the world, define the core conflict, and craft an engaging hook
3. **Possible Endings** — Design four distinct earned endings matching the template's four ending slots.
4. **Storytelling Style** — Determine narrative voice, tone, and pacing
5. **Presentation Notes** — Set language complexity, onomatopoeia usage, emoji preferences, etc.

## Output Discipline

- Output **only** the filled Act Plot template
- Include no preamble, explanation, or meta-commentary.
- Begin your response directly with the `# Act Plot` heading.
